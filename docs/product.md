# Producto SPulso

## Vision

Crear una plataforma de gestion humana superior a los sistemas tradicionales, con foco en automatizacion, multiempresa, experiencia visual moderna y autoservicio para trabajadores.

## Usuarios

- Administracion RRHH: gestiona trabajadores, asistencia, documentos, solicitudes, comunicados, beneficios y automatizaciones.
- Gerentes y jefes: revisan indicadores, equipos, aprobaciones y alertas.
- Trabajadores: marcan asistencia, revisan documentos, solicitan permisos/vacaciones, ven beneficios, comunicados y ficha laboral.

## Modulos del panel administrativo

- Dashboard operativo.
- Empresas.
- Trabajadores.
- Organizacion: areas, cargos y equipos.
- Usuarios y roles.
- Asistencia y reportes.
- Solicitudes.
- Documentos.
- Comunicados.
- Beneficios.
- Notificaciones.
- Automatizaciones.
- Auditoria.

## Modulos del portal trabajador

- Inicio.
- Marcacion con GPS.
- Solicitudes.
- Documentos.
- Mi equipo.
- Beneficios.
- Comunicados.
- Mi ficha.

## Antes de app movil

La web y API deben quedar estables, seguras y probadas. Luego se construye mobile en Flutter/Dart reutilizando la API existente.
